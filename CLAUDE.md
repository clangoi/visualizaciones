# Computación en movimiento

Sitio estático (HTML/CSS/JS sin compilación) publicado en GitHub Pages desde `main`.

- Antes de crear o modificar un tema, lea [GUIA_DE_ESTILO.md](GUIA_DE_ESTILO.md) y parta de [plantillas/tema.js](plantillas/tema.js).
- Después de cualquier cambio ejecute `npm run verificar` (o `npm run verificar -- <id>`); no dé por terminado un cambio con fallas.
- Ninguna sección del catálogo puede tener más de 12 temas: si se pasa, reestructúrela en secciones con nombres propios (ver la guía, §3).
- Colores solo desde `VIZ.color`; estilos estáticos solo en `css/estilos.css`.
- Hacer `git push` publica el sitio: confirme con el usuario antes.
